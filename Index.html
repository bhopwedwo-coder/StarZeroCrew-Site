Возможности

Всё нужное — без лишнего

Единая дизайн-система для сайта и приложения: понятные настройки, быстрый запуск и предсказуемое поведение на слабых машинах.

Гибкие настройки

Ключи, домены, порты и режимы обхода — в одном месте. Никаких скрытых конфигов и правки файлов вручную.

Профили конфигурации

Сохраняйте наборы настроек и переключайтесь между ними в один клик — для дома, работы или тестов.

Автоматический запуск

Старт вместе с Windows, работа в системном трее и запуск без открытого окна приложения.

Низкое потребление

Нативный .exe без Electron и фоновых сервисов: минимум ОЗУ и почти нулевая нагрузка на ЦП.

Минималистичный UI

Тёмная тема, крупные элементы управления и единая дизайн-система с этим сайтом.

Прозрачность

История обновлений, список изменений, контрольные суммы сборок и открытый код на GitHub.

Документация

От установки до удаления

Короткие и понятные инструкции: что делать при первом запуске, как настроить программу и как решить типовые проблемы.

01 Установка

Скачайте сборку со страницы релизов на GitHub — установщик .exe или портативный архив .zip.

  • Запустите установщик и подтвердите запрос UAC — программе нужны права администратора для работы с сетевым драйвером.
  • Windows SmartScreen может показать предупреждение: выберите «Подробнее» → «Выполнить в любом случае».
  • Для портативной версии просто распакуйте архив в отдельную папку — установка не требуется.
  • Сверьте SHA-256 скачанного файла с контрольной суммой из раздела обновлений.
02 Первый запуск

При первом старте приложение создаёт конфигурацию по умолчанию и проверяет наличие зависимостей.

  • Выберите профиль в списке — по умолчанию активен Default.
  • Нажмите переключатель, чтобы запустить обход. Индикатор состояния станет зелёным и начнёт пульсировать.
  • Проверьте работу в браузере. Если результат не изменился — смените профиль или режим перехвата.
  • Включите автозапуск, если хотите, чтобы профиль поднимался вместе с системой.
03 Описание настроек
  • Профиль — сохранённый набор параметров. Переключается мгновенно, без перезапуска окна.
  • Режим перехвата — способ обработки трафика: WinDivert (по умолчанию) или альтернативный драйвер.
  • Список доменов — адреса, к которым применяются правила обхода. По одному на строку.
  • Порты — диапазон портов для обработки: 80, 443 или собственный набор.
  • Автозапуск — добавляет программу в автозагрузку Windows и сворачивает её в трей.
  • Логи — журнал событий для диагностики; уровень детализации настраивается.
  • Прокси — отображает системный прокси Windows; предупреждает, если трафик идёт мимо Zapret.
  • Самовосстановление — перезапускает стратегию при потере связи с Discord и YouTube.
04 Решение распространённых проблем
  • Программа не запускается. Запустите от имени администратора и проверьте, не блокирует ли её антивирус.
  • Статус не становится активным. Убедитесь, что не запущена другая копия приложения или сторонний клиент, использующий тот же драйвер.
  • Нет эффекта на отдельных сайтах. Добавьте домен в список вручную и перезапустите профиль.
  • Пропадает соединение после запуска. Смените режим перехвата и проверьте настройки DNS.
  • Ошибка драйвера при старте. Переустановите приложение и перезагрузите систему.
  • Прокси мешает работе. Отключите системный прокси или настройте исключения.

Если проблема не решена — создайте issue на GitHub с логом из папки приложения.

05 Удаление программы
  • Остановите обход и закройте приложение через трей.
  • Отключите автозапуск, если он был включён.
  • Удалите программу через «Параметры» → «Приложения» → «Установленные приложения».
  • Для портативной версии достаточно удалить папку с файлами.
  • При необходимости удалите оставшуюся папку конфигурации в %APPDATA%\ZapretGUI.

Обновления и прозрачность

Каждая сборка сопровождается списком изменений, известными ошибками и контрольными суммами файлов.

Текущая сборка актуальная 2026
  • Улучшена стабильность запуска профилей на Windows 11 24H2.
  • Исправлено зависание индикатора состояния при быстром переключении.
  • Устранена утечка памяти в фоновом режиме трея.
  • Обновлена дизайн-система: единые цвета и отступы с сайтом.
  • Добавлен живой монитор связи (Discord / YouTube).
  • Горячая клавиша Ctrl+Alt+Z для включения и выключения защиты.
  • Избранные стратегии, 5 акцентных цветов, статистика дня.
  • Профили: стратегия + копия списков, переключение из трея.
  • Самовосстановление при потере связи.
Предыдущая сборка стабильная 2026
  • Живой монитор связи: проверка HTTPS до discord.com и www.youtube.com каждые 20 с.
  • Самовосстановление: перезапуск стратегии, затем автоподбор.
  • Горячая клавиша Ctrl+Alt+Z.
  • Избранные стратегии (звёздочка в списке и меню трея).
  • 5 акцентных цветов + свой цвет.
  • Статистика дня: время под защитой, сбои, перезапуски.
Архив ранние сборки 2026
  • Обход Instagram, Facebook / Meta, X (Twitter) и списка РКН.
  • Домены в lists\services\*.txt, автосборка list-services.txt.
  • Обновление списка РКН вручную и автоматически раз в N дней.
  • 4 темы (Тёмная, AMOLED, Графит, Ночь), 5 акцентов + свой цвет.
  • Настройки анимаций, лимит кадров, режим экономии памяти.
  • Пресеты «Минимум ресурсов» и «Максимум плавности».

Известные ошибки

  • На некоторых сборках Windows требуется ручная переустановка драйвера WinDivert.
  • Тёмная тема в трее может не применяться до перезапуска проводника.
  • Импорт профиля из старой версии выполняется только вручную.
